# Changelog

## Initial 0.1.0 releases — unreleased

These are the first planned crates.io releases. Each library is versioned and
published separately.

- **emoji-shortcodes:** iamcal and JoyPixels shortcode tables, Rocket.Chat
  aliases, and conversion between names and Unicode code points.
- **md-segments:** Markdown block segmentation, self-contained reference links,
  inline URL and emoji helpers, and optional syntect highlighting.
- **palette-rank:** fuzzy command ranking with stable tie order and result limits.
- **desktop-clipboard:** file-list and encoded-image clipboard acquisition,
  bounded PNG conversion, and typed errors. Optional decoded image fallback
  outside macOS.
- **desktop-notify:** macOS notifications, click routing, badges, and activation;
  explicit authorization and posting callbacks; optional notify-rust fallback.
- **slint-model-sync:** keyed, versioned row reconciliation, reuse across moves,
  and a read-only model facade that forwards Slint notifications.
- **slint-widgets:** copy and confirmation buttons, command palette, code and
  Markdown views, shared styling, keyboard input, and accessibility actions.

The gallery and headless test harness remain unpublished development tools.
